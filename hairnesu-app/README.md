# 配線表アプリ

PC でもスマホでも使える、配線表(ケーブル接続一覧)作成アプリです。
ビルド不要のバニラ HTML/CSS/JS 製の PWA (Progressive Web App) で、ブラウザだけで動作します。

## 特徴

- 接続一覧(表形式)の配線表を作成・編集
  - 接続元 / 接続元端子 / 接続先 / 接続先端子 / ケーブル種別 / ケーブルNo / 長さ / 色 / 備考
- 配線表は複数作成可能(左上のメニューから切り替え)
- CSV の読み込み・書き出し(Excel でそのまま開けます)
- スマホでもPCでも使えるレスポンシブUI
- オフラインでも動作(端末内 IndexedDB に自動保存)
- Supabase を設定すると PC とスマホでクラウド同期(任意)
- PWA としてホーム画面 / デスクトップにインストール可能(擬似デスクトップアプリ化)

## 動作確認・ローカルでの起動方法

このアプリはビルド不要です。静的ファイルとして配信するだけで動きます。

```bash
# このフォルダで簡易サーバーを起動(例: http-server)
npx http-server . -p 8080

# ブラウザで開く
# http://localhost:8080
```

Service Worker(オフライン対応)を使う都合上、`file://` で直接 `index.html` を開くのではなく、
必ず簡易サーバー経由(`http://localhost...` など)で開いてください。

## PC・スマホへの「インストール」(デスクトップアプリ化)

このアプリは PWA なので、Electron 等のネイティブアプリビルドをしなくても、
ブラウザから「インストール」するだけでデスクトップアプリ・スマホアプリのように使えます。

- **PC (Chrome / Edge)**: アドレスバー右側の「インストール」アイコン、またはメニューの
  「アプリをインストール」からインストールできます。インストール後はデスクトップアプリのように
  独立ウィンドウで起動します。
- **スマホ (iOS Safari)**: 共有ボタン →「ホーム画面に追加」
- **スマホ (Android Chrome)**: メニュー →「アプリをインストール」/「ホーム画面に追加」

## デプロイ(公開してどこからでも使えるようにする)

GitHub Pages / Netlify / Vercel / Cloudflare Pages など、静的ファイルをホスティングできる
サービスであればどこでも公開できます。ビルドコマンドは不要で、このフォルダの中身をそのまま
公開するだけです。

例: GitHub Pages の場合
1. このリポジトリを GitHub に push
2. Settings → Pages → Source を `main` ブランチ / ルートディレクトリに設定
3. 発行された URL にスマホ・PC どちらからでもアクセスできます

## クラウド同期(PCとスマホでデータを共有したい場合)

デフォルトでは配線表は端末内(ブラウザの IndexedDB)にのみ保存されます。
PC とスマホの間でデータを同期したい場合は、無料の [Supabase](https://supabase.com/) プロジェクトを
使ってクラウド同期を有効化できます。

1. Supabase でプロジェクトを作成
2. `supabase-schema.sql` の内容を Supabase ダッシュボードの SQL Editor で実行
   (テーブル作成 + Row Level Security 設定。自分のデータしか読み書きできないようになっています)
3. Supabase ダッシュボード → Project Settings → API から
   **Project URL** と **anon public key** を確認
4. アプリ右上のアカウントアイコンをタップし、その2つを入力して「保存して接続」
5. メールアドレス・パスワードで新規登録 → ログイン
6. 同じアカウントで別の端末からログインすると、配線表が同期されます

同期は「最後に更新した方を優先する」方式です。オフラインでも編集でき、次にオンラインになった
ときに自動的に同期されます。

## CSV 入出力

- 「CSV書出」: 現在開いている配線表を CSV でダウンロード(Excel で開けます)
- 「CSV読込」: CSV ファイルを読み込み、現在の配線表に追記または置き換え
  - 見出し行は「接続元, 接続元端子, 接続先, 接続先端子, ケーブル種別, ケーブルNo, 長さ(m), 色, 備考」

## ディレクトリ構成

```
index.html            アプリ本体(画面)
css/style.css         スタイル(PC/スマホ両対応のレスポンシブ)
src/app.js            画面の描画・操作ロジック
src/db.js             端末内保存(IndexedDB)
src/csv.js            CSV 入出力
src/cloud.js          クラウド同期(Supabase, 任意)
manifest.json         PWA マニフェスト
service-worker.js     オフラインキャッシュ
icons/                アプリアイコン
supabase-schema.sql   クラウド同期用の DB スキーマ
```

## 技術的な注意

- npm 等のパッケージは一切使用していません(ビルド不要)。Supabase の SDK のみ、ログイン機能を
  使う際にユーザーのブラウザから CDN (`esm.sh`) 経由で読み込まれます。未設定・未使用の場合は
  外部通信は一切発生しません。
